# sistema-gestion-ventas-python
# Kenneth Arias Solís

El objetivo de este proyecto es crear un sistema de ventas para una compañia o una tienda local como lo puede ser un ferreteria
el objetivo principal tras este proyecto es crear un orden, y una forma de llevar las cuentas e introducir los datos de manera más 
sencilla para la persona usando el programa

En este programa se a implementado un menú en el que al abrir el programa mostrara las opciones que tiene el usuario para realizar
tales como: realizar un movimiento/venta, guardar los datos introducidos en un archivo .csv y analizar los datos ya introducidos,
datos como el cliente al que más se le a vendido, el producto más popular o más vendido, y los ingresos de acuerdo con la fecha.

La ejecucion del programa es muy sencillo, en este a la hora de ejecutarlo mostrara un texto, en el que se indicara apretar ENTER para continuar
a continuacion se mostrará un menu en el que pedir al usuario introducir un numero segun la opcion que quiera utilizar
si desea ingresar un nuevo movimiento (venta), se le pedirá al usuario introducir los datos segun como se van pidiendo
una vez realizado el proceso se le mostará una lista de las ventas ya introducidas y si desea guardarla en un archivo
la segunda opcion le permitiras guardar esa informacion en un archivo .csv nombrado movimientos en le que se podra acceder si desea con la siguiente opcion
en la tercera opcion se le mostrará al usuario varios datos, como el total de ingresos, producto más vendido y ventas por fecha.

Un ejemplo del uso del programa puede ser el siguiente:
Supongamos que vendimos 2 martillos a 3000 colones cada uno a una persona
pues iriamos al programa e introduciriamos los siguientes datos, el producto, la cantidad, precio, cliente y fecha
la lista quedaria algo asi
MARTILLO, 2, 3000, 2020-07-25, Kenneth Arias

luego se intoduciria en el archivo csv y si es el unico dato dado, el analisis mostraria que:
el martillo es la herramienta más vendida
el mejor cliente o el que más a comprado seria Kenneth Arias
y luego mostraria que el 2020-07-25 las ventas serian de 6000 colones
